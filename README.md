# ValutaTrade Hub

ValutaTrade Hub — это учебный проект валютного кошелька на Python.

Программа позволяет регистрировать пользователей, создавать и просматривать валютные портфели, покупать, продавать валюту и получать информацию о курсах.
Данные пользователей, портфелей и валютных курсов сохраняются в json.

На текущем этапе используются тестовые курсы валют. Подключение внешних API будет реализовано позднее

## Запуск проекта

Проект использует Python 3.12+ и `uv` для управления окружением и зависимостями.

Для установки зависимостей выполните:

```
uv sync
```

После этого запустите программу:

```
uv run finalproject-korolev-m26-555
```

## Управление пользователями

После запуска программа ожидает ввода команд.

### Регистрация

Для регистрации нового пользователя используется команда:

```
register --username nikita --password 1234
```

Программа проверяет введеные данные, создает пользователя и пустой валютный портфель.
Пароли не сохраняются в открытом виде, для их хранения используется хеширование с индивидуальной солью.

### Авторизация

Для входа в систему используется команда:

```
login --username nikita --password 1234
```

После успешной авторизации становятся доступны операции с портфелем пользователя.

## Валютный портфель

Портфель содержит кошельки с балансами различных валют.
Для просмотра используется команда:

```
show-portfolio
```
При необходимости можно указать базовую валюту:

```
show-portfolio --base EUR
```

Программа выводит балансы кошельков, их оценочную стоимость и общую стоимость портфеля в выбранной валюте.

В проекте предусмотрены фиатные валюты и криптовалюты.


Для работы с валютами реализованы абстрактный класс `Currency` и классы `FiatCurrency`, `CryptoCurrency`.

## Покупка и продажа валют

### Покупка

Для покупки используется команда:

```
buy --currency BTC --amount 0.01
```

Программа проверяет валюту, количество и доступный баланс USD.
Если кошелька покупаемой валюты еще нет, он создается автоматически.
После покупки программа списывает стоимость операции с USD-кошелька, зачисляет валюту в соответствующий кошелек и сохраняет изменения.
Выводится количество купленной валюты, курс, изменение баланса и стоимость покупки.

### Продажа

Для продажи используется команда:

```
sell --currency BTC --amount 0.01
```

Программа проверяет наличие кошелька и достаточность средств.
При успешной продаже валюта списывается с соответствующего кошелька, а выручка зачисляется в USD.
После операции выводятся курс продажи, изменение баланса и выручка.
При недостаточном балансе операция не выполняется.

## Курсы валют

Для получения курса используется команда:

```
get-rate --from BTC --to USD
```

Программа выводит курс валютной пары, обратный курс и время последнего обновления.
Курсы сохраняются в `data/rates.json`.
Для проверки актуальности данных используется TTL — время, в течение которого курс считается действительным. Значение TTL задается в настройках проекта.
Если курс устарел, программа пытается его обновить.

## Обработка ошибок

В программе предусмотрены проверки входных данных, типы, значения аргументов и отдельные исключения.

- `CurrencyNotFoundError` — неизвестная валюта.
- `InsufficientFundsError` — недостаточно средств для выполнения операции.
- `ApiRequestError` — невозможно получить необходимый курс.

Ошибки обрабатываются в командном интерфейсе. Пользователь получает сообщение, без завершения работы программы.

## Логирование

Операции покупки и продажи записываются в журнал.
Для этого используется декоратор `@log_action`, который фиксирует действие, пользователя, валюту, количество, курс и результат выполнения.
При ошибках записываются тип исключения и сообщение.
При успешной работе сохраняются балансы до и после успешной операции.

Журнал находится в:

```
logs/actions.log
```

Для логирования используется стандартный модуль `logging` с ротацией файлов.

## Хранение данных и настройки

Для работы с json используется `DatabaseManager`.
Он отвечает за загрузку и сохранение данных, а бизнес-логика выполняет их изменение.
Сохранение json реализовано через временный файл и последующую замену основного файла, чтобы уменьшить риск повреждения данных при прерывании записи.
Настройки загружаются из `pyproject.toml` через `SettingsLoader`.
Оба класса реализованы с использованием паттерна Singleton.
В настройках указываются пути к файлам, базовая валюта, TTL курсов и параметры логирования.

## Структура проекта

```
valutatrade_hub/
    cli/
        interface.py
    core/
        currencies.py
        exceptions.py
        models.py
        usecases.py
        utils.py
    infra/
        database.py
        settings.py
    decorators.py
    logging_config.py

data/
    users.json
    portfolios.json
    rates.json

pyproject.toml
README.md
```

Основные модули:

- `models.py` — модели пользователей, кошельков и портфелей.
- `currencies.py` — классы валют и реестр поддерживаемых валют.
- `exceptions.py` — пользовательские исключения.
- `usecases.py` — регистрация, авторизация, торговые операции и работа с курсами.
- `utils.py` — функции чтения и сохранения json.
- `database.py` — управление json.
- `settings.py` — загрузка настроек.
- `decorators.py` — декоратор логирования операций.
- `logging_config.py` — настройка журнала.
- `interface.py` — командный интерфейс программы.
